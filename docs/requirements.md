# SDR 需求

当前执行范围为开源整理与最终结论收敛，硬件Goal未激活。用户已明确允许删除原始IQ/采集中间载荷；保留最终数值、条件、失败与未知。以下是设备需求基线，不构成自动恢复测试的指令。

将 UIS8910 改造成可重复使用的 SDR 接收设备：初始化 RF，配置中心频率/增益/带宽，采集解调前 IQ，通过 USB 交给 Windows 和通用 SDR 软件。允许经过 DFE/FIR/抽取，不依赖 SIM、入网或蜂窝解调。

1. 默认原生有符号 12 位数值，小端 16+16 位存储，每复数样点 4 字节。ENOB 不作为首版门槛；可选 8+8 位和紧凑 12 位尚未实现，只在实际收益支持时推进。
2. IQ 为纯 raw；无应用层包头、CRC、内容哈希、逐包 ACK 或重传。配置与统计独立；保留长度、cache、DMA 所有权及完成检查。允许损坏、丢块、间隙，损失必须如实报告。
3. 正常停止→排空→配置→重采不复位芯片，支持快速调参合并和错误恢复。不承诺无缝切频、精确时间戳或相位连续。
4. 使用少数有效 RF 路径取得尽可能宽的可靠范围。B40、B5/B8、B3优先；默认仅设频率并 Auto 选路。27 行仅供按需候选，不再逐行接入。芯片物理上下限仍是目标，必须区分软件、PLL/分频、模拟、板级前端和测量限制。
5. 保留 BW0–BW5。宽档允许部分传输，以 SDR 软件频率轴、参考峰、刷新和启停改参可用为验收目标。BW6/7 未证明新增通带，已收尾；新证据出现才重开。

新增测试范围按用户最新要求收敛：USB无法持续全量承载采样数据的带宽不再安排测试，不为既有宽档补通信或吞吐验收。当前通信只推进BW0/BW1（4字节/复数样点，分别7.68/15.36 MB/s）。BW2需要30.72 MB/s，当前30–32 MB/s基线没有充分持续余量，暂不纳入；BW3–BW5不进入后续通信测试。保留已经交付的宽档部分传输/频谱能力，不将它们变为新测试任务。
6. 以 UIS8910 SDK 原始二进制为行为依据，ZW217 为主要同代寄存器参考；前代精选源码用于具体对照。纳入 Air724UG 外部前端身份、RFFE 初始化/ID、接收开关及路径映射研究，以改善覆盖判断和 Auto 选路。保留必要厂商启动和板级校准，不猜写未知校准，不将其他模组的用料视为本板事实。
7. 交付可构建固件、Windows 库/CLI/raw、Soapy 和 SDR++ 原生插件，以及带条件和证据的能力表。验证真实数据流、改频和停止；用户已废弃桌面视觉验收，不再列为待办。
8. 必要 RAM 实验、软件恢复、固件修改已授权；PAC 先构建验证，由用户手动刷入。B210 有限发射并在实验后停止，物理重启和接线明确告知用户。

频率研究补充：手动实验路径取消标准频段包络，不逐段重刷放宽；保留接口表示、NV和初始化依赖。核对外部选路、RF模拟及DFE数字高通/低通/带通的使能或旁路；找到有代码依据的控制后允许开关对照，不将复位位当透明旁路。

暂停范围：BCPU 全 ROM、GSM/LTE 解调、ZSP、1090 MHz 扩展、全面冷启动精简、独立频谱 GUI。

所有收发实验均须考虑接收过饱和：从较低 UIS8910 接收增益开始，当前通信、双音参考及通带实验默认索引30，按具体频点证据再调整，不套用历史40/60。记录发射增益、数字源幅度及接收峰值/RMS/近轨比例；出现削顶或质量恶化时优先降低接收/发射电平。无数字削顶不能排除模拟级压缩，必要时用降低电平的单变量对照判断。低信号或未同步不能自动成为提高增益的理由。

通信实验按用户最新要求采用10秒有限发射及主机实时传输、解调，证明无线传输能力后收尾；60秒持续稳定性不再是门槛，也不继续扩展长测或功率网格。保留QPSK/OFDM独立载荷质量、实际获取率、损失、电平和停止排空证据。已有失败频点、旧长测失败及物理边界未知如实交付，不由短测追认为通过。

项目整理已完成，用户已恢复 Goal。按[主计划](plans/goal-roadmap.md)持续推进前端核对、RF覆盖和SDR交付。USB采用当前实测基线，只有明确退化、故障或实质收益依据时重开优化；不复活整套历史实验。
