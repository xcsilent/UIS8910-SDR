## RPM6743-31 与 RTM7916-51：资料来源、引脚、控制接口及 SDR 改造相关性

-   整理日期：2026-10-27
-   研究目标：了解基于 UIS8910DM 的蜂窝模组中，RPM6743-31、RTM7916-51
    两颗射频前端器件的公开开发资料，并评估它们对 SDR 接收链路的影响。
-   重要限制：本文汇总公开网页、第三方资料镜像和此前调查中可核验的信息。**不能替代芯片原厂完整数据手册、对应模组原理图或实测结果。**

## 1. 主要结论

1.  **RTM7916-51：已找到可直接打开的 PDF 规格书副本。**
    文档包含功能框图、引脚定义、MIPI RFFE
    信息、电气规格、评估板原理图、PCB 布局和封装尺寸。
2.  **RPM6743-31：已找到 Datasheet 资料页及附件名称，但完整 PDF
    的下载受到网站登录/付费限制。** 需要核对附件是否确实对应
    `RPM6743-31`，而不是其他 RPM6743 变体。
3.  两颗器件属于射频前端/功放与开关类器件，控制接口资料重点是 **MIPI
    RFFE**，不是面向用户的 AT 指令或 UART 数据协议。
4.  RTM7916-51 的 `ANT` 是天线侧射频端口；`TRX1` 至 `TRX14`
    为多路射频通路端口；`LB_IN`、`HB_IN`
    是功放射频输入相关端口。不要仅凭 `RFIN`
    名称把功放输入误认为接收机输入。
5.  对 UIS8910DM 的 SDR
    改造而言，**绕过外部前端不等于获得任意频率的宽带接收能力**。芯片内部
    RF
    接收机、频率合成器、模拟基带滤波器、采样率/数字滤波及固件配置仍可能限制接收范围。
6.  目前没有足够证据给出 UIS8910DM 裸芯片的具体 RF BGA 球位，或确认
    RPM6743-31/RTM7916-51 中某个引脚就是 UIS8910DM
    的直接接收输入。需要结合实际模组的原理图、PCB
    网络或实物测量继续追踪。

## 4. 对 UIS8910DM SDR 改造的意义

### 4.1 外部射频前端会限制频率响应

射频前端中的以下环节都可能造成某些频率接收弱或完全不可见：

-   射频开关：不同控制状态会选择不同的 RF 通路。
-   SAW/BAW 滤波器、双工器：按目标频段设计，带外信号可能显著衰减。
-   阻抗匹配网络：通常只在指定频率范围内实现较低损耗。
-   FEM 内部的 PA、开关及滤波结构：可能让部分路径仅适用于特定蜂窝频段。

但不能仅凭"集成功放/开关"就断言某颗芯片会滤除所有非 LTE
频率；需要查看具体通路和滤波器频响。

### 4.2 绕过 FEM 仍然不等于宽带 SDR

即使从外部前端旁路，UIS8910DM 仍可能受以下因素限制：

1.  RF 接收机实际支持的频率范围；
2.  PLL/LO 的可调谐范围及频率步进；
3.  RF 输入结构、差分/单端形式和输入匹配；
4.  芯片内部模拟滤波器及接收带宽配置；
5.  ADC、采样率、抽取和数字滤波；
6.  固件中接收路径、增益、频段和校准配置。

因此，发现某些频率无信号时，不能直接归因于 RPM6743-31 或 RTM7916-51。

### 4.3 不建议的做法

-   不要把天线直接接到 RPM6743-31 的 `RFIN_L/M/H` 一类功放输入端。
-   不要在不知道 UIS8910DM RF
    输入球位、输入阻抗和匹配要求的情况下，直接将 50 Ω 天线焊到 SoC
    球位。
-   不要在没有确认发射状态和输入功率限制时，向模组射频端口注入高功率信号。
-   不要把其他展锐平台的参考原理图直接当作 UIS8910DM 的实际网络连接图。

### 4.4 推荐的调查流程

1.  获取目标模组（如 Air724UG 或 EC200U）的真实原理图/BOM。
2.  从天线端 `ANT` / `LTE_ANT` 开始，逐网追踪匹配网络、滤波器、FEM 和
    SoC 端。
3.  根据 RTM7916-51 的 `ANT`、`TRXx`、`LB_IN`、`HB_IN`
    等定义识别信号方向。
4.  取得 RPM6743-31 对应 `-31` 版本的完整手册后，核对其 Pin Map 和 RFFE
    寄存器。
5.  找到 UIS8910DM
    实际接收端的网络和球位；核实输入结构、匹配及频率范围后，再评估是否能建立旁路测试通路。
6.  用已知频率、低功率信号源和衰减器进行测试，比较正常频段与异常频段的
    IQ 结果。

### 8.4 拆解报告对 SDR 分析的直接启示

1.  **不要将 RPM6743-31 与 RTM7916-51 视作串联的两颗普通滤波器。**
    它们是具有不同功放和切换功能的射频前端器件；实际链路可能存在分支、端口选择和频段依赖。
2.  **不能由器件存在就推断某个频率必然被滤掉。**
    需要知道目标信号经过哪一个端口、开关状态、滤波器/双工器的频率响应和匹配网络。
3.  **GNSS 链路要单独看。** UC6228CI 是独立 GNSS SoC，GPS L1 约 1575.42
    MHz 等定位信号的接收路径与 UIS8910DM 的蜂窝 RF 接收通路不同。分析
    GNSS 接收时，不要把它误当作 UIS8910DM 的 LTE 前端。
4.  **照片能识别器件，不能替代网表。** 若要确定天线到 UIS8910DM
    的实际路径，需要 EC200U
    对应版本的原理图，或通过断电测量、网络分析和连续性测试确认 PCB
    走线。
5.  **RPM6743-31 的"RX/TX"文字要谨慎解释。** 拆解文章用"RX and TX
    block"描述其所在射频区域，但其后列出的内部功能包括多频段功放路径和切换输出。应以具体
    Datasheet
    的端口定义和框图判断每个端口的信号方向，不能据此认定它是通用 LNA
    或宽带接收放大器。

### 8.5 拆解文章的局限

-   没有提供 EC200U 完整电路图、BOM、PCB 层叠或完整网络连接表。
-   没有逐颗识别全部 SAW/BAW 滤波器、双工器、天线匹配电感/电容的型号。
-   没有给出 RPM6743-31 或 RTM7916-51 在 EC200U 上的完整 RFFE
    寄存器初始化序列。
-   没有实测各 RF 通路的插入损耗、回波损耗或滤波器频响。
-   没有证明某颗独立 LTE LNA
    的具体型号；因此不应从照片直接下结论说某个小封装器件就是 LNA。

### 9.5 如果源码里确实有这两颗 FEM 的操作代码，应该重点看什么？

对 `RPM6743-31` 和 `RTM7916-51`，优先定位以下文件或符号：

  ------------------------------------------------------------------------------------------------------------------------
  搜索目标                可能出现的名称/关键词                                      需要确认的内容
  ----------------------- ---------------------------------------------------------- -------------------------------------
  器件驱动文件            `rpm6743`、`rtm7916`、`pa_*`、`rf_*`、`fem_*`              驱动入口、器件型号、适用平台

  MIPI RFFE 总线层        `rffe`、`mipi`、`SCLK`、`SDATA`、`USID`、`slave address`   RFFE 主控接口、从设备地址、读写函数

对 SDR
